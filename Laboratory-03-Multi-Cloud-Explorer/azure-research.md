# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft and officially launched in 2010. It provides cloud services for computing, networking, storage, databases, artificial intelligence, analytics, security, IoT, and application development.

Azure is especially useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, SQL Server, and .NET applications. It also supports hybrid cloud environments, allowing organizations to connect existing on-premises infrastructure with cloud services.

## 2. Global Infrastructure

Microsoft Azure operates a global infrastructure made up of Regions, Availability Zones, and Region Pairs.

An Azure Region is a geographical area containing one or more data centers connected through high-speed networks. Organizations can select regions based on factors such as user location, performance, data requirements, and operational needs.

Within many Azure Regions, Microsoft provides Availability Zones. These are physically separate data centers with independent power, cooling, and networking infrastructure. Availability Zones help improve high availability, fault tolerance, business continuity, and disaster recovery.

Azure also uses Region Pairs. A Region Pair connects an Azure Region with another region within the same geographic area. Region pairs can support disaster recovery and data replication if a large-scale outage affects one region.

## 3. Cloud Management Console

The Azure Portal is Microsoft's web-based graphical interface for managing Azure resources and services. It provides a centralized dashboard where users can create, configure, monitor, and secure cloud resources.

Through the Azure Portal, users can create virtual machines, configure storage accounts, build virtual networks, manage databases, monitor resource performance, manage identities and permissions, and review billing and subscription information.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtual servers that allow organizations to run operating systems and applications in the cloud. They can be used for hosting websites, enterprise applications, databases, development environments, and remote desktop systems.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data. It can store documents, images, videos, backups, website assets, and application files.

### Azure Virtual Network

Azure Virtual Network (VNet) allows organizations to create secure virtual networks within Azure. It provides private IP addresses, subnets, routing, network security groups, VPN connectivity, and hybrid cloud networking.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage user identities, authentication, Single Sign-On (SSO), Multi-Factor Authentication (MFA), and access permissions.

## 5. Three Advantages

### Integration with Microsoft Technologies

Azure works well with Microsoft products and technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID. This makes Azure a strong option for organizations that already depend on Microsoft's ecosystem.

### Hybrid Cloud Support

Azure supports hybrid cloud environments, allowing organizations to connect their existing on-premises infrastructure with Azure services. This can help organizations gradually migrate their systems to the cloud.

### Global Infrastructure

Azure provides Regions, Availability Zones, and Region Pairs that support availability, performance, and disaster recovery. Organizations can select appropriate regions based on their users and operational requirements.

## 6. Typical Enterprise Use Cases

Microsoft Azure is commonly used by enterprises for hosting applications, running virtual machines, storing data and backups, managing databases, building secure networks, and managing user identities.

Azure is also suitable for organizations that want hybrid cloud environments. For example, a company using Windows Server and Microsoft technologies can extend some of its existing infrastructure to Azure instead of completely replacing its current systems.
