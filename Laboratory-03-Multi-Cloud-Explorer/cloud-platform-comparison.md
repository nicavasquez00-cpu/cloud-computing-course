## 2. Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services among the three major cloud providers. It provides services for computing, storage, networking, databases, security, artificial intelligence, machine learning, analytics, and application development.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies because it works well with products such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID. It is also suitable for organizations that want to connect their existing on-premises systems with cloud services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is one of the strongest choices for Artificial Intelligence and Kubernetes. The module identifies GCP as being strong in AI, machine learning, cloud-native technologies, and Kubernetes, including Google Kubernetes Engine (GKE).

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it offers a broad range of cloud services that can support different types of projects. It would also give me the opportunity to learn about computing, storage, databases, networking, security, and other cloud technologies on one platform.
